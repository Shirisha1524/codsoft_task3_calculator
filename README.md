# codsoft_task3_calculator
This is a basic calculator web application built using HTML, CSS, and JavaScript. It performs essential arithmetic operations like Addition, Subtraction, Multiplication, and Division, and also includes a clean and responsive UI design.
🔧 How It Works

The user clicks the buttons displayed on the interface.

The clicked values (numbers & operators) appear in the display screen.

When the user presses the = (equal) button, JavaScript evaluates the expression.

The Clear (C) button resets the display.

🧠 Features

User-friendly and responsive layout.

Clean display output using HTML.

Styled using custom CSS for an attractive UI.

Functional JavaScript logic to handle calculations.

Option to add extra features like:

Keyboard input support

Calculation history


📂 Technologies Used

HTML – Structure of the calculator.

CSS – Styling, layout, buttons, and responsive design.

JavaScript – Functional logic for calculations and display handling.
